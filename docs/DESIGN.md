# 设计说明

## 为什么分层

把“写作时怎么写”和“写完后查什么”放在同一提示词中，会让模型在生成时过早自检，造成僵硬、规整和新的 AI 腔。因此本项目将写作档、修订档、防拟合协议分离，并在入口中明确加载边界。

## 三种记忆

- 项目记忆：世界规则、主线、时间线和作者声音。
- 章节记忆：本章入场/收场状态与连续性变化。
- 请求记忆：本次任务的视角、事件、结果、效果和限制。

文件只是载体，不能把缺失事实当成事实补齐。

## 质量观

本 Skill 不以“每段一样长”“每章固定节拍”或“禁用所有高频词”为质量标准。核心评价是事件是否落地、人物是否主动、反应是否具体、状态是否连续，以及句子是否服务于本作声音。
