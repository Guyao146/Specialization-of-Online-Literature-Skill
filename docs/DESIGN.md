# 设计说明

## 为什么分层

把“写作时怎么写”和“写完后查什么”放在同一提示词中，会让模型在生成时过早自检，造成僵硬、规整和新的 AI 腔。因此本项目将焚诀写作档、焚诀修订档与防拟合协议分离：正文先在不读取病征表的条件下完成草稿，再加载修订规则扫查，最后只输出修订稿。

防拟合协议只处理过度拟合，不承担原作设定、世界观、角色 OOC、剧情逻辑或跨作品语域判断。这些问题由原作资料、设定卡、章纲和评审负责。

## 三种记忆

- 项目记忆：原作基准、世界规则、主线、时间线和作者声音。
- 章节记忆：本章入场/收场状态与连续性变化。
- 请求记忆：本次任务的视角、事件、结果、效果和限制。

文件只是载体，不能把缺失事实当成事实补齐。

## 质量观

本 Skill 不以“每段一样长”或“每章固定节拍”为质量标准。核心评价是事件是否落地、人物是否主动、反应是否具体、状态是否连续，以及句子是否服务于本作声音。作者声音以《文风参考文本（非正文剧情）》和当前已有正文为锚点；防拟合规则不能反过来成为新文风。
