# 贡献与迭代规范

## 提交规则变更

1. 说明规则解决的具体问题，并附最小复现片段。
2. 标记规则类型：`writing`、`revision`、`anti-overfitting`、`format` 或 `schema`。
3. 不把修订用硬删表、限量表、提示项或其他病征表加入 `writing.md`。
4. 给出一个容易误伤的反例，说明规则边界。
5. 更新 `CHANGELOG.md`，运行 `scripts/validate.ps1`。

防拟合规则必须保持全同人通用，不加入某个原著题材、跨界设定或西幻/东方玄幻专属语域判断。设定正确性、世界观、角色 OOC 和剧情逻辑应进入项目模板或评审规则。

## 版本原则

- 破坏调用方式或输出契约：递增主版本。
- 新增兼容规则或模板：递增次版本。
- 澄清文字、修复链接或校验：递增修订版本。

## 样本与版权

只提交自有或明确获授权的正文样本。不要把可识别的在世作者风格指令作为默认规则；项目应学习抽象特征和本作自身样本，而不是复制外部作品。
