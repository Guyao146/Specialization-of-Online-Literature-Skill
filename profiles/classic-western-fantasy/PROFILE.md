# 古典西幻特化档 v1

## 适用范围

适用于古典西幻方向的原创与同人创作。用户明确选择“西幻特化”“古典西幻”或本档名称时，使用本档；未明确选择时，不自动用本档覆盖通用规则。

## 路由

1. 所有阶段先加载 `prompts/core.md`。
2. 写作阶段只加载 `prompts/writing.md` 与 `prompts/format.md`，不得读取负向病征。
3. 草稿完成后，加载 `prompts/revision.md` 做正向连续性检查，再加载 `prompts/anti-overfitting.md` 与 `prompts/lexicon.md` 做负向扫查。
4. 讨论、章纲与评审仍可使用根目录对应规则，但世界观、角色 OOC、剧情逻辑和跨作品语域不得交给防拟合协议处理。
5. 最终只输出修订后的正文；内部推演、草稿、扫查过程不输出。

## 优先级

用户指令与核心剧情 ＞ 事实因果与视角连续 ＞ 声音与人物 ＞ 篇幅、节奏与形式。

本作已定稿正文是声音本体。文风参考只提供句法、对话断行、叙述距离与场景推进方向，不提供人物、地名、组织、仪式、桥段或专有概念。
