# 焚诀·西幻版 v1：写作档

写作时只读取本文件、同档 `core.md` 与 `format.md`，不读取防拟合协议或西幻词表。

## 一、写作档

1.1 先想“发生了什么、谁在承受、他会怎么反应”，再想句子长什么样。先出现句式、再填充事件，作废。

1.2 视角 `[硬]`：一章一个主视角。允许章内切换与群像，但按剧情自适应选择，且每次切换要有明确分隔与理由。

1.3 叙述距离 `[执]`：以限知为主，叙述者知道的不得超过视角人物能知道的。家族史与旧事插叙是例外，按 1.9 执行。

1.4 对话 `[硬]`：说话人身份由上下文、动作、状态或环境自然成立；允许“他说／她说／XX道”，这是译本腔本体。禁止汇报式台词。对话前宜有动作或状态，但不必句句都配。

1.5 反应落地 `[硬]`：每个笑点、威胁、转折或伤口落地后，至少让一个在场人物做出具体反应，例如回嘴、岔开、做别的事或留下沉默。不得用“没接话”“沉默了几秒”充当反应本身。

1.6 留空 `[执]`：全章最关键的那一下落地之后先留空，不许立刻用动作、解释或旁人反应盖过去。

1.7 节奏 `[许]`：允许跑题、长段和某一段不精致；节奏可以故意不均，不为“呼吸”强行修剪。单章标准约 4000 字，场景 2～4 个。

1.8 梗不回收 `[执]`：笑点落地后最多留一个即时反应；旁观者确认、旁白命名和事后总结，删除。

1.9 家族史与旧事插叙 `[执]`：这是古典西幻的骨架之一，鼓励使用，但须同时满足：

1. 由当下场景触发，例如物件、口头禅、地名、气味或伤口；
2. 插叙结束回到当下时，有身体或动作的落点；
3. 单次不超过全章五分之一；
4. 同章不超过两次。

1.10 人物 `[硬]`：人物可以判断错、反应过度、选择次优。主角连续做出最优判断，视为重大瑕疵。

1.11 世界观呈现 `[硬]`：冷门概念首次出现只给最小定位——是什么、为何异常、造成什么后果。不解释不必要的设定。宗教、巫术和预言只给现象、仪式、身体反应与代价，不给机制说明。

1.12 器物与生活质感 `[执]`：写衣食住行、兵器、礼仪、病程、取暖和货币时，写实物、重量、温度与时间，不写抽象形容词。

1.13 称谓 `[硬]`：按身份、场合、亲疏三个维度选择。同一人物在不同人嘴里的称谓不同，是信息，不是错误。越级称呼必须让在场人物有反应。

1.14 命名 `[硬]`：新创能力、术式、咒语、地名和组织名必须有来路——谁命名的，来自哪种语言、事件或地理位置。禁止中文诗化长句命名，禁止无来源的拉丁转写与宗教腔命名。

1.15 穿越者与现代词 `[硬]`：现代词只允许出现在穿越者角色的言语与内心，以及以穿越者为视角人物的段落；其他叙述者语言不得使用。全书无穿越者时，本条作废。

1.16 亲密戏 `[许]`：按用户给出的剧情点写，完全放开，不作病征判定。只保留指代清楚与动作可读两条底线。

## 四、西幻专属条款（按需调用）

4.1 头衔与称谓：按本档 `lexicon.md` 第四节执行。

4.2 纹章、族语、誓言、仪典 `[许·备用]`：出场即给功能，例如宣誓、识别、挑衅或效忠；不给背景讲座。族语一句话就够，不要翻译成诗。

4.3 器物与冷兵器 `[执]`：兵器写重量、长度、磨损、保养与拿法；盔甲写声音、温度和穿脱时间。禁止用“寒光一闪”“杀气凛然”等无信息形容替代实物。

4.4 地理与气候 `[执]`：距离用时间，例如走几天；温度用身体，例如手指僵、呼吸有白汽；饥寒用后果。地图不解释，人物走过的路才是地图。

4.5 宗教、巫术、预言 `[硬]`：只写仪式流程、身体反应、代价与后果。禁止“其实是因为……”式机制解释。预言不解释、不圆场。

4.6 群像与视角切换 `[许·备用]`：群像场景一拍至少有一人被跳过、被打断、被代答或选择不表态。切换视角必须有明确分隔。

4.7 中世纪生活常识 `[执·备用]`：涉及病程、取暖、食物保存、货币购买力和夜间光源时，下笔前先问一句“这个时代有没有它”。
